# ¡Vamos! — site
Static landing + Privacy Policy + Terms (PT primary, EN in /en). Edit `build.py` (APP name, placeholders) and run `python3 build.py`.

Landing-page screenshots were refreshed on 2026-10-16 from vamos-app commit `84714f2`, using a 430×932 viewport and the app’s isolated QA demo states. The same Portuguese app screenshots appear on both language versions.

Public website: https://vamos.acedigitallabs.com

GitHub Pages publishes `main` from the repository root. Keep the `CNAME` file when regenerating the site. HostGator DNS routes the `vamos` subdomain to `jpaaquino.github.io` with a CNAME record.
